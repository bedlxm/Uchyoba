## 2. Расчёт методом контурных токов (МКТ)

3. Контурный ток $I_{33}$ — замыкается через ветвь с источником тока $J_4$ по петле (1-4-2-1):
   $$I_{33} = \underline{J}_4 = \mathbf{-3 - j 3\text{ А}}$$

### Связь реальных токов ветвей с контурными токами:
* Ветвь 1: $\underline{I}_1 = -I_{11}$ *(ток течёт навстречу обходу $I_{11}$)*;

## 5. Проверка баланса мощностей

Условие баланса мощностей: $\sum \underline{S}_{ист} = \sum \underline{S}_{потр}$.

### 5.1. Комплексная мощность потребителей:
$$\underline{S}_{потр} = I_1^2 \underline{Z}_1 + I_2^2 \underline{Z}_2 + I_3^2 \underline{Z}_3 + I_4^2 \underline{Z}_4 + I_5^2 \underline{Z}_5$$

* $I_1^2 = 3^2 + 3^2 = 18 \implies I_1^2 \underline{Z}_1 = 18 \cdot (50 + j 30) = 900 + j 540\text{ В}\cdot\text{А}$
* $I_2^2 = 1^2 + 4^2 = 17 \implies I_2^2 \underline{Z}_2 = 17 \cdot 50 = 850 + j 0\text{ В}\cdot\text{А}$
* $I_3^2 = (-1)^2 + (-4)^2 = 17 \implies I_3^2 \underline{Z}_3 = 17 \cdot 40 = 680 + j 0\text{ В}\cdot\text{А}$
* $I_4^2 = (-3)^2 + (-3)^2 = 18 \implies I_4^2 \underline{Z}_4 = 18 \cdot (40 + j 10) = 720 + j 180\text{ В}\cdot\text{А}$
* $I_5^2 = (-2)^2 + 1^2 = 5 \implies I_5^2 \underline{Z}_5 = 5 \cdot (-j 100) = 0 - j 500\text{ В}\cdot\text{А}$

$$\mathbf{P_{потр} = 900 + 850 + 680 + 720 = 3150\text{ Вт}}$$
$$\mathbf{Q_{потр} = 540 + 0 + 0 + 180 - 500 = 220\text{ ВАр}}$$
$$\underline{S}_{потр} = \mathbf{3150 + j 220\text{ В}\cdot\text{А}}$$

### 5.2. Комплексная мощность источников:
* Источник $\underline{E}_1$: ток $\underline{I}_1$ течёт навстречу стрелке $\underline{E}_1$:
  $$\underline{S}_{E1} = -\underline{E}_1 \underline{I}_1^* = -(-300 + j 200)(3 - j 3) = 300 - j 1500\text{ В}\cdot\text{А}$$
* Источник $\underline{E}_6$: ток ветви $\underline{I}_6 = 0 \implies \underline{S}_{E6} = 0$.
* Источник $\underline{E}_5$: ток $\underline{I}_5$ течёт по стрелке $\underline{E}_5$:
  $$\underline{S}_{E5} = \underline{E}_5 \underline{I}_5^* = (190 + j 560)(-2 - j 1) = 180 - j 1310\text{ В}\cdot\text{А}$$
* Источник тока $\underline{J}_4$:
  $$\underline{U}_{J4} = \dot{\varphi}_4 - \dot{\varphi}_1 + \underline{I}_4 \underline{Z}_4 = (150 - j 800) + (-3 - j 3)(40 + j 10) = 60 - j 950\text{ В}$$
  $$\underline{S}_{J4} = \underline{U}_{J4} \underline{J}_4^* = (60 - j 950)(-3 + j 3) = 2670 + j 3030\text{ В}\cdot\text{А}$$

Суммарная комплексная мощность источников:
$$\underline{S}_{ист} = (300 + 0 + 180 + 2670) + j (-1500 + 0 - 1310 + 3030) = \mathbf{3150 + j 220\text{ В}\cdot\text{А}}$$

$$\mathbf{P_{ист} = 3150\text{ Вт}}, \qquad \mathbf{Q_{ист} = 220\text{ ВАр}}$$

### Оценка погрешности баланса:
$$\Delta = \left|\frac{P_{ист} - P_{потр}}{P_{потр}}\right| \cdot 100\% = \mathbf{0{,}00\%} \le 3\%$$
Баланс сошёлся с абсолютной математической точностью.

## Пункт 2. Расчёт токов по ветвям методом контурных токов (МКТ)

### 2.1. Составление канонической системы уравнений МКТ

$$\begin{cases}

\underline{I}_{11} \underline{Z}_{11} + \underline{I}_{22} \underline{Z}_{12} + \underline{I}_{33} \underline{Z}_{13} = \underline{E}_{11} \\
\underline{I}_{11} \underline{Z}_{21} + \underline{I}_{22} \underline{Z}_{22} + \underline{I}_{33} \underline{Z}_{23} = \underline{E}_{22}
\end{cases}$$

Определим коэффициенты системы:
1. **Собственные сопротивления контуров I и II (со знаком «$+$»):**
   * В контур I входят ветви 1, 6 и 3 ($\underline{Z}_6 = 0$):
     $$\underline{Z}_{11} = \underline{Z}_1 + \underline{Z}_3 = (50 + j 30) + 40 = 90 + j 30\text{ Ом}$$
   * В контур II входят ветви 2, 3 и 5:
     $$\underline{Z}_{22} = \underline{Z}_2 + \underline{Z}_3 + \underline{Z}_5 = 50 + 40 - j 100 = 90 - j 100\text{ Ом}$$
2. **Взаимные сопротивления между контурами:**
   * Между контурами I и II общая ветвь 3 ($\underline{Z}_3 = 40\text{ Ом}$). Контурный ток $\underline{I}_{11}$ течёт по ней вправо, а $\underline{I}_{22}$ — влево (навстречу друг другу $\implies$ знак «$-$»):
     $$\underline{Z}_{12} = \underline{Z}_{21} = -\underline{Z}_3 = -40\text{ Ом}$$
   * Между контурами I и III общая ветвь 6, в которой нет резисторов, катушек или конденсаторов ($\underline{Z}_6 = 0$):
     $$\underline{Z}_{13} = 0\text{ Ом}$$
   * Между контурами II и III общая ветвь 2 ($\underline{Z}_2 = 50\text{ Ом}$). Ток $\underline{I}_{22}$ течёт по ней сверху вниз, а $\underline{I}_{33}$ — снизу вверх (навстречу друг другу $\implies$ знак «$-$»):
     $$\underline{Z}_{23} = -\underline{Z}_2 = -50\text{ Ом}$$
3. **Контурные ЭДС (при обходе против часовой стрелки):**
   * В контуре I обе стрелки источников $\underline{E}_1$ (влево) и $\underline{E}_6$ (вправо) совпадают с направлением обхода $\underline{I}_{11}$:

     $$\underline{E}_{22} = \underline{E}_5 = 190 + j 560\text{ В}$$

Записываем систему уравнений:
$$\begin{cases}
\underline{I}_{11}(\underline{Z}_1 + \underline{Z}_3) - \underline{I}_{22} \underline{Z}_3 = \underline{E}_1 + \underline{E}_6 \\
-\underline{I}_{11} \underline{Z}_3 + \underline{I}_{22}(\underline{Z}_2 + \underline{Z}_3 + \underline{Z}_5) - \underline{I}_{33} \underline{Z}_2 = \underline{E}_5
\end{cases}$$

Переносим известное слагаемое $-\underline{I}_{33} \underline{Z}_2 = -\underline{J}_4 \underline{Z}_2$ в правую часть второго уравнения:
$$\underline{E}_5 + \underline{J}_4 \underline{Z}_2 = (190 + j 560) + (-3 - j 3) \cdot 50 = (190 + j 560) + (-150 - j 150) = 40 + j 410\text{ В}$$

Получаем итоговую систему двух уравнений:

## Пункт 3. Система уравнений для определения токов методом узловых потенциалов (МУП)

### 3.1. Система уравнений МУП в общем (буквенном) виде

\underline{\varphi}_1 = 0 \\
\underline{\varphi}_2 = \underline{E}_6 \\
\text{Узел 3:} \quad \underline{\varphi}_3 \left(\dfrac{1}{\underline{Z}_1} + \dfrac{1}{\underline{Z}_3} + \dfrac{1}{\underline{Z}_5}\right) - \underline{\varphi}_1 \dfrac{1}{\underline{Z}_1} - \underline{\varphi}_2 \dfrac{1}{\underline{Z}_3} - \underline{\varphi}_4 \dfrac{1}{\underline{Z}_5} = -\dfrac{\underline{E}_1}{\underline{Z}_1} + \dfrac{\underline{E}_5}{\underline{Z}_5} \\[10pt]
\text{Узел 4:} \quad -\underline{\varphi}_2 \dfrac{1}{\underline{Z}_2} - \underline{\varphi}_3 \dfrac{1}{\underline{Z}_5} + \underline{\varphi}_4 \left(\dfrac{1}{\underline{Z}_2} + \dfrac{1}{\underline{Z}_5}\right) = -\dfrac{\underline{E}_5}{\underline{Z}_5} + \underline{J}_4
\end{cases}$$

*(Пояснение знаков в правых частях: к узлу 3 стрелка $\underline{E}_1$ направлена **от узла** $\implies -\dfrac{\underline{E}_1}{\underline{Z}_1}$, а стрелка $\underline{E}_5$ направлена **к узлу** $\implies +\dfrac{\underline{E}_5}{\underline{Z}_5}$. К узлу 4 стрелка $\underline{E}_5$ направлена **от узла** $\implies -\dfrac{\underline{E}_5}{\underline{Z}_5}$, а стрелка источника тока $\underline{J}_4$ направлена **к узлу** $\implies +\underline{J}_4$).*

Подставляя $\underline{\varphi}_1 = 0$ и перенося известные слагаемые с $\underline{\varphi}_2 = \underline{E}_6$ в правую часть, получаем расчётную систему из двух уравнений:

$$\begin{cases}
\underline{\varphi}_3 \left(\dfrac{1}{\underline{Z}_1} + \dfrac{1}{\underline{Z}_3} + \dfrac{1}{\underline{Z}_5}\right) - \underline{\varphi}_4 \dfrac{1}{\underline{Z}_5} = -\dfrac{\underline{E}_1}{\underline{Z}_1} + \dfrac{\underline{E}_5}{\underline{Z}_5} + \dfrac{\underline{E}_6}{\underline{Z}_3} \\[10pt]
-\underline{\varphi}_3 \dfrac{1}{\underline{Z}_5} + \underline{\varphi}_4 \left(\dfrac{1}{\underline{Z}_2} + \dfrac{1}{\underline{Z}_5}\right) = -\dfrac{\underline{E}_5}{\underline{Z}_5} + \underline{J}_4 + \dfrac{\underline{E}_6}{\underline{Z}_2}
\end{cases}$$

### 3.2. Подстановка численных данных и решение системы МУП

Подставляем комплексные сопротивления ветвей ($\underline{Z}_1 = 50 + j 30$, $\underline{Z}_2 = 50$, $\underline{Z}_3 = 40$, $\underline{Z}_5 = -j 100$) и значения источников:

$$\begin{cases}
\underline{\varphi}_3 \left(\dfrac{1}{50 + j 30} + \dfrac{1}{40} + \dfrac{1}{-j 100}\right) - \underline{\varphi}_4 \dfrac{1}{-j 100} = -\dfrac{-300 + j 200}{50 + j 30} + \dfrac{190 + j 560}{-j 100} + \dfrac{200 - j 600}{40} \\[12pt]
-\underline{\varphi}_3 \dfrac{1}{-j 100} + \underline{\varphi}_4 \left(\dfrac{1}{50} + \dfrac{1}{-j 100}\right) = -\dfrac{190 + j 560}{-j 100} + (-3 - j 3) + \dfrac{200 - j 600}{50}
\end{cases}$$

#### Шаг 1. Вычисление дробей и коэффициентов в скобках

Избавимся от комплексности в знаменателях, домножая числитель и знаменатель на сопряжённое выражение (с учётом того, что $\dfrac{1}{-j} = +j$):

1. **Обратные сопротивления ветвей $\dfrac{1}{\underline{Z}_k}$:**
   * $\dfrac{1}{\underline{Z}_1} = \dfrac{1}{50 + j 30} = \dfrac{50 - j 30}{50^2 + 30^2} = \dfrac{50 - j 30}{3400} = \dfrac{5 - j 3}{340}\text{ См} \approx 0{,}01471 - j 0{,}00882\text{ См}$
   * $\dfrac{1}{\underline{Z}_2} = \dfrac{1}{50} = 0{,}02\text{ См}$
   * $\dfrac{1}{\underline{Z}_3} = \dfrac{1}{40} = 0{,}025\text{ См}$
   * $\dfrac{1}{\underline{Z}_5} = \dfrac{1}{-j 100} = +j 0{,}01\text{ См}$

2. **Скобки в левой части уравнений:**
   * Коэффициент при $\underline{\varphi}_3$ в первом уравнении:
     $$\dfrac{1}{\underline{Z}_1} + \dfrac{1}{\underline{Z}_3} + \dfrac{1}{\underline{Z}_5} = \dfrac{5 - j 3}{340} + 0{,}025 + j 0{,}01 = \dfrac{135 + j 4}{3400}\text{ См} \approx 0{,}03971 + j 0{,}00118\text{ См}$$
   * Коэффициент при $\underline{\varphi}_4$ во втором уравнении:
     $$\dfrac{1}{\underline{Z}_2} + \dfrac{1}{\underline{Z}_5} = 0{,}02 + j 0{,}01\text{ См}$$

3. **Правая часть первого уравнения (для узла 3):**
   * $-\dfrac{\underline{E}_1}{\underline{Z}_1} = -\dfrac{-300 + j 200}{50 + j 30} = \dfrac{(300 - j 200)(50 - j 30)}{3400} = \dfrac{9000 - j 19000}{3400} = \dfrac{90 - j 190}{34}\text{ А} \approx 2{,}6471 - j 5{,}5882\text{ А}$
   * $\dfrac{\underline{E}_5}{\underline{Z}_5} = \dfrac{190 + j 560}{-j 100} = j \dfrac{190 + j 560}{100} = -5{,}6 + j 1{,}9\text{ А}$
   * $\dfrac{\underline{E}_6}{\underline{Z}_3} = \dfrac{200 - j 600}{40} = 5 - j 15\text{ А}$
   * Сумма в правой части 1-го уравнения:
     $$-\dfrac{\underline{E}_1}{\underline{Z}_1} + \dfrac{\underline{E}_5}{\underline{Z}_5} + \dfrac{\underline{E}_6}{\underline{Z}_3} = \dfrac{90 - j 190}{34} + (-5{,}6 + j 1{,}9) + (5 - j 15) = \dfrac{69{,}6 - j 635{,}4}{34}\text{ А} \approx 2{,}0471 - j 18{,}6882\text{ А}$$

4. **Правая часть второго уравнения (для узла 4):**
   * $-\dfrac{\underline{E}_5}{\underline{Z}_5} = -\dfrac{190 + j 560}{-j 100} = 5{,}6 - j 1{,}9\text{ А}$
   * $\underline{J}_4 = -3 - j 3\text{ А}$
   * $\dfrac{\underline{E}_6}{\underline{Z}_2} = \dfrac{200 - j 600}{50} = 4 - j 12\text{ А}$
   * Сумма в правой части 2-го уравнения:
     $$-\dfrac{\underline{E}_5}{\underline{Z}_5} + \underline{J}_4 + \dfrac{\underline{E}_6}{\underline{Z}_2} = (5{,}6 - j 1{,}9) + (-3 - j 3) + (4 - j 12) = 6{,}6 - j 16{,}9\text{ А}$$

#### Шаг 2. Запись упрощённой системы и нахождение $\underline{\varphi}_3, \underline{\varphi}_4$ по правилу Крамера

Система в десятичном виде:
$$\begin{cases}
(0{,}03971 + j 0{,}00118)\underline{\varphi}_3 - j 0{,}01\,\underline{\varphi}_4 = 2{,}0471 - j 18{,}6882 \\
-j 0{,}01\,\underline{\varphi}_3 + (0{,}02 + j 0{,}01)\underline{\varphi}_4 = 6{,}6 - j 16{,}9
\end{cases}$$

Чтобы считать без погрешностей округления, умножим первое уравнение на общий знаменатель $3400$, а второе — на $100$:
$$\begin{cases}
(135 + j 4)\underline{\varphi}_3 - j 34\,\underline{\varphi}_4 = 6960 - j 63540 \\
-j\,\underline{\varphi}_3 + (2 + j)\underline{\varphi}_4 = 660 - j 1690
\end{cases}$$

1. **Главный определитель системы $\Delta$:**
   $$\Delta = \begin{vmatrix} 135 + j 4 & -j 34 \\ -j 1 & 2 + j 1 \end{vmatrix} = (135 + j 4)(2 + j 1) - (-j 34)(-j 1)$$
   $$\Delta = (270 + j 135 + j 8 - 4) + 34 = \mathbf{300 + j 143}$$

2. **Определитель $\Delta_3$ и потенциал $\underline{\varphi}_3$:**
   $$\Delta_3 = \begin{vmatrix} 6960 - j 63540 & -j 34 \\ 660 - j 1690 & 2 + j 1 \end{vmatrix} = (6960 - j 63540)(2 + j 1) - (-j 34)(660 - j 1690)$$
   $$\Delta_3 = (13920 + j 6960 - j 127080 + 63540) + (57460 + j 22440) = 134920 - j 97680$$
   $$\underline{\varphi}_3 = \frac{\Delta_3}{\Delta} = \frac{134920 - j 97680}{300 + j 143} = \frac{(134920 - j 97680)(300 - j 143)}{300^2 + 143^2} = \frac{26507760 - j 48597560}{110449} = \mathbf{240 - j 440\text{ В}}$$

3. **Определитель $\Delta_4$ и потенциал $\underline{\varphi}_4$:**
   $$\Delta_4 = \begin{vmatrix} 135 + j 4 & 6960 - j 63540 \\ -j 1 & 660 - j 1690 \end{vmatrix} = (135 + j 4)(660 - j 1690) - (-j 1)(6960 - j 63540)$$
   $$\Delta_4 = (89100 - j 228150 + j 2640 + 6760) + (63540 + j 6960) = 159400 - j 218550$$
   $$\underline{\varphi}_4 = \frac{\Delta_4}{\Delta} = \frac{159400 - j 218550}{300 + j 143} = \frac{(159400 - j 218550)(300 - j 143)}{300^2 + 143^2} = \frac{16567350 - j 88359200}{110449} = \mathbf{150 - j 800\text{ В}}$$

### 3.3. Нахождение токов в ветвях по обобщённому закону Ома и I закону Кирхгофа

Подставляем найденные потенциалы узлов ($\underline{\varphi}_1 = 0$, $\underline{\varphi}_2 = 200 - j 600\text{ В}$, $\underline{\varphi}_3 = 240 - j 440\text{ В}$, $\underline{\varphi}_4 = 150 - j 800\text{ В}$):

   $$\underline{I}_1 = \frac{\underline{\varphi}_1 - \underline{\varphi}_3 - \underline{E}_1}{\underline{Z}_1} = \frac{0 - (240 - j 440) - (-300 + j 200)}{50 + j 30} = \frac{60 + j 240}{50 + j 30} = \mathbf{3 + j 3\text{ А}}$$

3. **Ток $\underline{I}_3$:**
   $$\underline{I}_3 = \frac{\underline{\varphi}_2 - \underline{\varphi}_3}{\underline{Z}_3} = \frac{(200 - j 600) - (240 - j 440)}{40} = \frac{-40 - j 160}{40} = \mathbf{-1 - j 4\text{ А}}$$
4. **Ток $\underline{I}_4$:**
   $$\underline{I}_4 = \underline{J}_4 = \mathbf{-3 - j 3\text{ А}}$$
5. **Ток $\underline{I}_5$:**
   $$\underline{I}_5 = \frac{\underline{\varphi}_4 - \underline{\varphi}_3 + \underline{E}_5}{\underline{Z}_5} = \frac{(150 - j 800) - (240 - j 440) + (190 + j 560)}{-j 100} = \frac{100 + j 200}{-j 100} = \mathbf{-2 + j 1\text{ А}}$$
6. **Ток $\underline{I}_6$ (по I закону Кирхгофа для узла 2):**
   $$\underline{I}_6 - \underline{I}_2 - \underline{I}_3 = 0 \implies \underline{I}_6 = \underline{I}_2 + \underline{I}_3 = (1 + j 4) + (-1 - j 4) = \mathbf{0\text{ А}}$$

## Пункт 5. Проверка баланса мощностей

Условие комплексного баланса мощностей в цепи переменного тока:
$$\boxed{\underline{S}_{ист} = \underline{S}_{потр}} \iff \begin{cases} \sum P_{ист} = \sum P_{потр} \\ \sum Q_{ист} = \sum Q_{потр} \end{cases}$$

---

### 5.1. Комплексная мощность приёмников (потребителей) $\underline{S}_{потр}$

Полная комплексная мощность приёмников равна сумме мощностей во всех пассивных ветвях ($\underline{S}_k = I_k^2 \cdot \underline{Z}_k$):
1. Квадраты модулей действующих токов ветвей:
   * $I_1^2 = 3^2 + 3^2 = 18\text{ А}^2$
   * $I_2^2 = 1^2 + 4^2 = 17\text{ А}^2$
   * $I_3^2 = (-1)^2 + (-4)^2 = 17\text{ А}^2$
   * $I_4^2 = (-3)^2 + (-3)^2 = 18\text{ А}^2$
   * $I_5^2 = (-2)^2 + 1^2 = 5\text{ А}^2$
2. Мощности отдельных ветвей:
   * $\underline{S}_1 = I_1^2 \underline{Z}_1 = 18 \cdot (50 + j 30) = 900 + j 540\text{ В}\cdot\text{А}$
   * $\underline{S}_2 = I_2^2 \underline{Z}_2 = 17 \cdot 50 = 850 + j 0\text{ В}\cdot\text{А}$
   * $\underline{S}_3 = I_3^2 \underline{Z}_3 = 17 \cdot 40 = 680 + j 0\text{ В}\cdot\text{А}$
   * $\underline{S}_4 = I_4^2 \underline{Z}_4 = 18 \cdot (40 + j 10) = 720 + j 180\text{ В}\cdot\text{А}$
   * $\underline{S}_5 = I_5^2 \underline{Z}_5 = 5 \cdot (-j 100) = 0 - j 500\text{ В}\cdot\text{А}$

Суммируем мощности всех потребителей:
$$\underline{S}_{потр} = \sum_{k=1}^5 I_k^2 \underline{Z}_k = (900 + 850 + 680 + 720) + j(540 + 180 - 500) = \mathbf{3150 + j 220\text{ В}\cdot\text{А}}$$
* Активная мощность потребителей: $P_{потр} = 3150\text{ Вт}$;
* Реактивная мощность потребителей: $Q_{потр} = 220\text{ ВАр}$.

### 5.2. Определение напряжения на зажимах источника тока $\underline{U}_{J4}$

Запишем уравнение по **II закону Кирхгофа** для левого нижнего контура (Контур III: через ветвь 4, ветвь 2 и ветвь 6):
$$-\underline{U}_{J4} + \underline{I}_4 \underline{Z}_4 - \underline{I}_2 \underline{Z}_2 = -\underline{E}_6 \implies \underline{U}_{J4} = \underline{E}_6 + \underline{I}_4 \underline{Z}_4 - \underline{I}_2 \underline{Z}_2$$

Подставляем численные значения:

$$\underline{U}_{J4} = (200 - j 600) + (-90 - j 150) - (50 + j 200) = \mathbf{60 - j 950\text{ В}}$$

### 5.3. Комплексная мощность источников питания $\underline{S}_{ист}$

Комплексная мощность источников вычисляется с использованием **сопряжённых комплексов токов** ($\underline{I}_k^*$):
$$\underline{S}_{ист} = -\underline{E}_1 \underline{I}_1^* + \underline{E}_5 \underline{I}_5^* + \underline{E}_6 \underline{I}_6^* + \underline{U}_{J4} \underline{J}_4^*$$
*(Пояснение знаков: стрелка $\underline{E}_1$ направлена навстречу току $\underline{I}_1 \implies$ знак «$-$»; стрелки $\underline{E}_5$ и $\underline{E}_6$ сонаправлены с токами $\underline{I}_5$ и $\underline{I}_6 \implies$ знак «$+$»).*

Вычисляем слагаемые:
1. Сопряжённые токи ветвей с источниками:
   * $\underline{I}_1 = 3 + j 3\text{ А} \implies \underline{I}_1^* = 3 - j 3\text{ А}$
   * $\underline{I}_5 = -2 + j 1\text{ А} \implies \underline{I}_5^* = -2 - j 1\text{ А}$
   * $\underline{I}_6 = 0\text{ А} \implies \underline{I}_6^* = 0\text{ А}$
   * $\underline{J}_4 = -3 - j 3\text{ А} \implies \underline{J}_4^* = -3 + j 3\text{ А}$
2. Мощность каждого источника:

   * $\underline{S}_{E6} = +\underline{E}_6 \underline{I}_6^* = (200 - j 600) \cdot 0 = 0\text{ В}\cdot\text{А}$
   * $\underline{S}_{J4} = +\underline{U}_{J4} \underline{J}_4^* = (60 - j 950)(-3 + j 3) = 2670 + j 3030\text{ В}\cdot\text{А}$

Суммируем мощности всех источников:
$$\underline{S}_{ист} = (300 + 180 + 0 + 2670) + j(-1500 - 1310 + 0 + 3030) = \mathbf{3150 + j 220\text{ В}\cdot\text{А}}$$

> [!success] Итог проверки баланса мощностей
> $$\underline{S}_{ист} = 3150 + j 220\text{ В}\cdot\text{А} \equiv \underline{S}_{потр} = 3150 + j 220\text{ В}\cdot\text{А}$$
> * $P_{ист} = P_{потр} = 3150\text{ Вт}$ (погрешность $0\%$)
> * $Q_{ист} = Q_{потр} = 220\text{ ВАр}$ (погрешность $0\%$)
> 
> Баланс активных и реактивных мощностей выполняется абсолютно точно!

## 1. Законы Кирхгофа (для мгновенных и комплексных значений)

### 1.1. Система дифференциально-интегральных уравнений для мгновенных значений

> [!note] Физический закон и правила знаков
> * **Первый закон Кирхгофа (I ЗК):** $\sum i_{\text{втек}} - \sum i_{\text{вытек}} = 0$. Токи, вытекающие из узла, берём со знаком «$-$», втекающие — со знаком «$+$».
> * **Второй закон Кирхгофа (II ЗК):** $\sum u_k(t) = \sum e_k(t)$. Падение напряжения на резисторе равно $R i(t)$, на катушке индуктивности — $L \frac{di(t)}{dt}$, на конденсаторе — $\frac{1}{C}\int i(t) dt$. Обход обоих контуров выбираем **против часовой стрелки**.

Составляем систему уравнений:
$$\begin{cases}
\text{Узел 1:} & -i_1(t) - i_6(t) - J_4(t) = 0 \\
\text{Узел 2:} & i_6(t) - i_2(t) - i_3(t) = 0 \\
\text{Узел 3:} & i_1(t) + i_3(t) + i_5(t) = 0 \\
\text{Контур I (1-2-3-1):} & i_3(t) R_3 - i_1(t) R_1 - L_1 \dfrac{di_1(t)}{dt} = e_6(t) + e_1(t) \\
\text{Контур II (2-4-3-2):} & i_2(t) R_2 + \dfrac{1}{C_5}\displaystyle\int i_5(t)\,dt - i_3(t) R_3 = e_5(t)
\end{cases}$$

---

### 1.2. Система уравнений в комплексной форме действующих значений

Применяя символический метод (метод комплексных амплитуд):
* $i(t) \to \underline{I}$
* $\dfrac{di(t)}{dt} \to j\omega \underline{I} \implies L \dfrac{di(t)}{dt} \to j\omega L \underline{I} = j X_L \underline{I}$
* $\displaystyle\int i(t)\,dt \to \dfrac{1}{j\omega} \underline{I} \implies \dfrac{1}{C}\displaystyle\int i(t)\,dt \to -j \dfrac{1}{\omega C} \underline{I} = -j X_C \underline{I}$

Получаем систему комплексных алгебраических уравнений:
$$\begin{cases}
-\underline{I}_1 - \underline{I}_6 = \underline{J}_4 \\
-\underline{I}_2 - \underline{I}_3 + \underline{I}_6 = 0 \\
\underline{I}_1 + \underline{I}_3 + \underline{I}_5 = 0 \\
-\underline{I}_1 \underline{Z}_1 + \underline{I}_3 \underline{Z}_3 = \underline{E}_1 + \underline{E}_6 \\
\underline{I}_2 \underline{Z}_2 - \underline{I}_3 \underline{Z}_3 + \underline{I}_5 \underline{Z}_5 = \underline{E}_5
\end{cases}$$

#### Матричная форма $[Z] \cdot [\underline{I}] = [\underline{B}]$:
$$\begin{pmatrix}
-1 & 0 & 0 & 0 & -1 \\
0 & -1 & -1 & 0 & 1 \\
1 & 0 & 1 & 1 & 0 \\
-(50 + j 30) & 0 & 40 & 0 & 0 \\
0 & 50 & -40 & -j 100 & 0
\end{pmatrix}
\cdot
\begin{pmatrix}
\underline{I}_1 \\
\underline{I}_2 \\
\underline{I}_3 \\
\underline{I}_5 \\
\underline{I}_6
\end{pmatrix}
=
\begin{pmatrix}
-3 - j 3 \\
0 \\
0 \\
-100 - j 400 \\
190 + j 560
\end{pmatrix}$$

*(Примечание: правая часть контура I равна $\underline{E}_1 + \underline{E}_6 = (-300 + j 200) + (200 - j 600) = -100 - j 400\text{ В}$).*

## 5. Проверка баланса мощностей

> [!important] Формула комплексного баланса мощностей
> В разветвлённой цепи синусоидального тока сумма комплексных мощностей источников равна сумме комплексных мощностей потребителей:
> $$\sum \underline{S}_{ист} = \sum \underline{S}_{потр} \iff \begin{cases} \sum P_{ист} = \sum P_{потр} \\ \sum Q_{ист} = \sum Q_{потр} \end{cases}$$

### 5.1. Комплексная мощность потребителей $\underline{S}_{потр}$
$$\underline{S}_{потр} = \sum_{k=1}^5 I_k^2 \underline{Z}_k = I_1^2 \underline{Z}_1 + I_2^2 \underline{Z}_2 + I_3^2 \underline{Z}_3 + I_4^2 \underline{Z}_4 + I_5^2 \underline{Z}_5$$

* $I_1^2 = 3^2 + 3^2 = 18\text{ А}^2 \implies \underline{S}_1 = 18 \cdot (50 + j 30) = 900 + j 540\text{ В}\cdot\text{А}$
* $I_2^2 = 1^2 + 4^2 = 17\text{ А}^2 \implies \underline{S}_2 = 17 \cdot 50 = 850 + j 0\text{ В}\cdot\text{А}$
* $I_3^2 = (-1)^2 + (-4)^2 = 17\text{ А}^2 \implies \underline{S}_3 = 17 \cdot 40 = 680 + j 0\text{ В}\cdot\text{А}$
* $I_4^2 = (-3)^2 + (-3)^2 = 18\text{ А}^2 \implies \underline{S}_4 = 18 \cdot (40 + j 10) = 720 + j 180\text{ В}\cdot\text{А}$
* $I_5^2 = (-2)^2 + 1^2 = 5\text{ А}^2 \implies \underline{S}_5 = 5 \cdot (-j 100) = 0 - j 500\text{ В}\cdot\text{А}$

Суммируем:
$$\mathbf{P_{потр} = 900 + 850 + 680 + 720 + 0 = 3150\text{ Вт}}$$
$$\mathbf{Q_{потр} = 540 + 0 + 0 + 180 - 500 = 220\text{ ВАр}}$$
$$\underline{S}_{потр} = \mathbf{3150 + j 220\text{ В}\cdot\text{А}}$$

---

### 5.2. Комплексная мощность источников $\underline{S}_{ист}$

   * Источник $\underline{E}_1$ (ток направлен навстречу стрелке ЭДС $\implies$ знак «$-$»):

   * Источник $\underline{E}_5$ (ток сонаправлен со стрелкой ЭДС $\implies$ знак «$+$»):
     $$\underline{S}_{E5} = +\underline{E}_5 \underline{I}_5^* = (190 + j 560)(-2 - j 1) = (-380 + 560) + j (-190 - 1120) = 180 - j 1310\text{ В}\cdot\text{А}$$
   * Источник $\underline{E}_6$:
     $$\underline{S}_{E6} = \underline{E}_6 \underline{I}_6^* = (200 - j 600) \cdot 0 = 0\text{ В}\cdot\text{А}$$
   * Источник тока $\underline{J}_4$:
     $$\underline{S}_{J4} = \underline{U}_{J4} \underline{J}_4^* = (60 - j 950)(-3 + j 3) = (-180 + 2850) + j (180 + 2850) = 2670 + j 3030\text{ В}\cdot\text{А}$$

4. **Суммарная комплексная мощность источников:**
   $$\underline{S}_{ист} = (300 + 180 + 0 + 2670) + j (-1500 - 1310 + 0 + 3030) = \mathbf{3150 + j 220\text{ В}\cdot\text{А}}$$
   $$\mathbf{P_{ист} = 3150\text{ Вт}}, \qquad \mathbf{Q_{ист} = 220\text{ ВАр}}$$

### 6.2. Топографическая векторная диаграмма напряжений

Топографическая диаграмма строится по потенциалам узлов и падениям напряжений на элементах цепи:
* $\dot{\varphi}_1 = (0;\ 0)\text{ В}$
* $\dot{\varphi}_2 = (200;\ -600)\text{ В}$
* $\dot{\varphi}_3 = (240;\ -440)\text{ В}$

1. **От узла 1 к узлу 2:** через идеальный источник $\underline{E}_6$:
   $$\dot{\varphi}_2 - \dot{\varphi}_1 = \underline{E}_6 = 200 - j 600\text{ В}$$
2. **От узла 2 к узлу 4:** через резистор $R_2$ по току $\underline{I}_2$:
   $$\dot{\varphi}_2 - \underline{I}_2 R_2 = (200 - j 600) - (50 + j 200) = (150;\ -800)\text{ В} = \dot{\varphi}_4$$
3. **От узла 4 к узлу 3:** через источник $\underline{E}_5$ и конденсатор $C_5$:
   * Прибавляем $\underline{E}_5 = 190 + j 560\text{ В} \implies (150 - j 800) + (190 + j 560) = (340;\ -240)\text{ В}$

4. **От узла 3 к узлу 1:** через элементы $R_1, L_1$ и источник $\underline{E}_1$:

### 5.1. Комплексная мощность приёмников (потребителей)
Квадраты действующих значений (модулей) токов в ветвях ($I_k^2 = \text{Re}(\underline{I}_k)^2 + \text{Im}(\underline{I}_k)^2$):

### 5.2. Напряжение на зажимах источника тока $\underline{U}_{J4}$ и мощность источников
