## 1. Эквивалентные преобразования пассивных цепей

> [!info] Последовательное соединение элементов
> Соединение, при котором элементы находятся в одной ветви, то есть по ним протекает один и тот же ток.
> $$R_{экв} = R_1 + R_2 + \dots + R_n$$

> [!info] Параллельное соединение элементов
> Соединение, при котором элементы присоединены к одной паре узлов, то есть находятся под одинаковым напряжением $U$.
> 
> Расчёт ведётся через эквивалентную проводимость $g_{экв} = \dfrac{1}{R_{экв}}$ $[\mathrm{Sm}]$:
> $$g_{экв} = g_1 + g_2 + \dots + g_n$$
> Для двух параллельных ветвей:
> $$R_{экв} = \frac{R_1 \cdot R_2}{R_1 + R_2}$$

### 1.1. Практические примеры свёртывания цепей

> [!example] Пример 1. Расчёт цепи с несколькими параллельными группами
> Даны параллельные участки:
> * Два резистора по $10\ \Omega$ в параллель:
>   $$R' = \frac{10 \cdot 10}{10 + 10} = 5\ \Omega$$
> * Два резистора по $12\ \Omega$ в параллель:
>   $$R'' = \frac{12 \cdot 12}{12 + 12} = 6\ \Omega$$

> [!example] Пример 2. Неразветвлённая цепь с противоположными источниками ЭДС
> **Дано:** $E_1 = 12\text{ В}$, $E_2 = 24\text{ В}$, $R_1 = 1\ \Omega$, $R_2 = 2\ \Omega$, $R_3 = 3\ \Omega$.  
> Найти ток в цепи:
> $$I = \frac{E_1 - E_2}{R_1 + R_2 + R_3} = \frac{12 - 24}{1 + 2 + 3} = \frac{-12}{6} = -2\text{ А}$$
> *(Знак «минус» означает, что реальный ток течёт навстречу выбранному направлению, то есть в сторону действия большего источника $E_2$).*

### 1.2. Преобразование «Треугольник $\to$ Звезда» ($\Delta \to \text{Y}$) в мостовой схеме

Схема содержит мост сопротивлений ($R_1, R_2, R_3, R_4, R_5$), подключённый к источнику $E$. Для упрощения треугольник сопротивлений преобразуется в эквивалентную трёхлучевую звезду:

#### Формулы эквивалентного преобразования треугольника $(1-2-3)$ в звезду:
$$R^* = R_1 + R_2 + R_3$$
$$R_{13} = \frac{R_1 \cdot R_2}{R^*}, \qquad R_{12} = \frac{R_1 \cdot R_3}{R^*}, \qquad R_{23} = \frac{R_2 \cdot R_3}{R^*}$$

#### Дальнейшие шаги свёртывания:
1. $R^1 = R_{12} + R_4$ (последовательное соединение);
2. $R^2 = R_{23} + R_5$ (последовательное соединение);
3. $R^3 = \dfrac{R^1 \cdot R^2}{R^1 + R^2}$ (параллельное соединение двух полученных ветвей);
4. $R_{экв} = R_{13} + R^3$.

## 2. Расчёт цепей постоянного тока по законам Кирхгофа

> [!tip] Топологический расчёт числа независимых уравнений
> * По I закону Кирхгофа: $K_I = у - 1$
> * По II закону Кирхгофа: $K_{II} = в - в_J - (у - 1)$
> * Всего неизвестных токов: $в - в_J$

---

* Число уравнений по I З.К.: $K_I = 5 - 1 = 4$

#### Система уравнений по законам Кирхгофа:
$$\begin{cases}
\text{Узел 1:} & I_1 - I_2 + J_{k1} = 0 \\
\text{Узел 2, 5:} & I_5 + I_3 - J_{k2} - J_{k1} = 0 \\
\text{Узел 3:} & I_2 - I_3 + I_4 + J_{k2} = 0 \\
\text{Узел 4:} & -I_1 - I_4 - I_5 = 0 \\
\text{Контур I:} & -I_1 R_1 - I_2 R_2 + I_4 R_4 = E_1 \\
\text{Контур II:} & -I_4 R_4 + I_5 R_5 - I_3 R_3 = 0
\end{cases}$$

#### Матричная форма $[A] \cdot [I] = [B]$:
$$\begin{pmatrix}
1 & -1 & 0 & 0 & 0 \\
0 & 0 & 1 & 0 & 1 \\
0 & 1 & -1 & 1 & 0 \\
-R_1 & -R_2 & 0 & R_4 & 0 \\
0 & 0 & -R_3 & -R_4 & R_5
\end{pmatrix}
\cdot
\begin{pmatrix}
I_1 \\ I_2 \\ I_3 \\ I_4 \\ I_5
\end{pmatrix}
=
\begin{pmatrix}
-J_{k1} \\
J_{k2} + J_{k1} \\
-J_{k2} \\
E_1 \\
0
\end{pmatrix}$$

## 3. Метод контурных токов (МКТ) для цепей постоянного тока

> [!tip] Правило для контуров с источником тока
> Если в цепи присутствует ветвь с источником тока $J_k$, соответствующий контурный ток выбирается замыкающимся через этот источник тока и становится сразу известным:
> $$I_{33} = J_k$$
> Это уравнение не составляется по II закону Кирхгофа, а подставляется в остальные уравнения, сокращая размерность решаемой системы.

---

#### Канонические уравнения МКТ:
$$\begin{cases}
I_{11}(R_1 + R_2) - I_{22} R_2 - I_{33} R_1 = -E_2 - E_5 \\
-I_{11} R_2 + I_{22}(R_2 + R_3) - I_{33} R_3 = E_2 - E_4 \\
I_{33} = J_k
\end{cases}$$

Подставляя известное $I_{33} = J_k$:
$$\begin{cases}
I_{11}(R_1 + R_2) - I_{22} R_2 = -E_2 - E_5 + J_k R_1 \\
-I_{11} R_2 + I_{22}(R_2 + R_3) = E_2 - E_4 + J_k R_3
\end{cases}$$

#### Связь реальных токов ветвей с контурными токами:
$$I_1 = I_{11} - I_{33}, \quad I_2 = I_{22} - I_{11}, \quad I_3 = I_{33} - I_{22}, \quad I_4 = I_{22}, \quad I_5 = I_{11}$$

## 4. Метод узловых потенциалов (МУП) для цепей постоянного тока

> [!tip] Опорный узел при идеальном источнике ЭДС
> Если между узлами 1 и 4 включён идеальный источник ЭДС $E_1$ (без резистора), принимаем:
> $$\varphi_1 = 0 \implies \varphi_4 = E_1 \quad (\text{или } \varphi_4 = 0 \implies \varphi_1 = -E_1)$$
> Это исключает составление уравнения для узла 4 и снижает число неизвестных.

---

### Задача 4.1. Система МУП для цепи с 4 узлами

$$\begin{cases}
\varphi_1 = 0 \\
\varphi_4 = E_1 \\
\varphi_2 \left(\dfrac{1}{R_4} + \dfrac{1}{R_2} + \dfrac{1}{R_5}\right) - \varphi_3 \dfrac{1}{R_5} = \dfrac{E_2}{R_2} \\
-\varphi_2 \dfrac{1}{R_5} + \varphi_3 \left(\dfrac{1}{R_3} + \dfrac{1}{R_5} + \dfrac{1}{R_6}\right) = \dfrac{E_6}{R_6} + J_{k1} + \dfrac{E_1}{R_3}
\end{cases}$$

#### Выражение токов ветвей по закону Ома:
$$I_6 = \frac{\varphi_3 - \varphi_1 - E_6}{R_6}, \quad I_4 = \frac{\varphi_1 - \varphi_2}{R_4}, \quad I_2 = \frac{\varphi_4 - \varphi_2}{R_2}$$
$$I_5 = \frac{\varphi_2 - \varphi_3}{R_5}, \quad I_3 = \frac{\varphi_4 - \varphi_3}{R_3}, \quad I_1 = I_2 + I_3$$

## 5. Баланс мощностей для цепей постоянного тока

> [!warning] Допустимая погрешность расчёта
> В инженерных расчётах сходимость баланса мощностей проверяется формулой:
> $$\Delta = \left|\frac{P_{ист} - P_{потр}}{P_{потр}}\right| \cdot 100\% \le 3\%$$

* **Мощность потребителей:**
  $$P_{потр} = \sum_{k=1}^n I_k^2 R_k$$

* **Мощность источников:**
  $$P_{ист} = \sum E_k I_k + \sum J_k U_{ab}$$
  где $U_{ab}$ — падение напряжения на зажимах источника тока, определяемое по II закону Кирхгофа:
  $$U_{ab} = I_5 R_5 + I_4 R_4$$

### 1.1. Шаг 1: Перевод параметров в комплексную форму

1. **Начальные фазы источников:** перевод из радиан в градусы:
   $$e(t) = E_m \sin(\omega t + \psi_E) \implies \underline{E} = \frac{E_m}{\sqrt{2}} e^{j \psi_E}$$

2. **Комплексные сопротивления ветвей цепи:**
   * **Ветвь 1:** чисто индуктивная:
     $$\underline{Z}_1 = j X_{L1} = X_{L1} e^{j 90^\circ}$$
   * **Ветвь 2:** последовательное $R_2$ и $C_2$:
     $$\underline{Z}_2 = R_2 - j X_{C2} = \sqrt{R_2^2 + X_{C2}^2} e^{-j \operatorname{arctg}\left(\frac{X_{C2}}{R_2}\right)} = Z_2 e^{j \varphi_2}$$
   * **Ветвь 3:** чисто активная:
     $$\underline{Z}_3 = R_3$$
   * **Ветвь 4:** последовательное $R_4, L_4, C_4$:
     $$\underline{Z}_4 = R_4 + j(X_{L4} - X_{C4}) = \sqrt{R_4^2 + (X_{L4} - X_{C4})^2} e^{j \operatorname{arctg}\left(\frac{X_{L4} - X_{C4}}{R_4}\right)} = Z_4 e^{j \varphi_4}$$

## 2. Расчёт комплексной цепи по законам Кирхгофа

* Топология: $у = 4$, $в = 6$, $в_J = 1$.
* Уравнений по I З.К.: $K_I = 4 - 1 = 3$
* Уравнений по II З.К.: $K_{II} = 6 - 1 - 4 + 1 = 2$

### 2.1. Система уравнений:

#### По I закону Кирхгофа:
$$\begin{cases}
\text{Узел 1:} & \underline{I}_5 + \underline{I}_1 - J_k = 0 \\
\text{Узел 2:} & \underline{I}_1 - \underline{I}_3 - \underline{I}_4 = 0 \\
\text{Узел 3:} & \underline{I}_3 - J_k + \underline{I}_2 = 0
\end{cases}$$

#### По II закону Кирхгофа:
$$\begin{cases}
\text{Контур I:} & \underline{I}_1 j X_{L1} + \underline{I}_4 R_4 + \underline{I}_4 j X_{L4} + \underline{I}_4 (-j X_{C4}) = \underline{E}_5 \\
\text{Контур II:} & \underline{I}_2 R_2 + \underline{I}_2 (-j X_{C2}) - \underline{I}_3 R_3 - \underline{I}_1 j X_{L1} = \underline{E}_2 - \underline{E}_3
\end{cases}$$

Матричная форма записи: $[\underline{I}] = [\underline{Z}]^{-1} \cdot [\underline{E}]$.

## 3. Расчёт методом контурных токов (МКТ)

Выбираем контурный ток через источник тока: $\underline{I}_{33} = J_k$.

$$\begin{cases}
\underline{I}_{11}(\underline{Z}_1 + \underline{Z}_4) - \underline{I}_{22} \underline{Z}_1 + \underline{I}_{33} \underline{Z}_4 = \underline{E}_5 \\
\underline{I}_{22}(\underline{Z}_1 + \underline{Z}_2 + \underline{Z}_3) - \underline{I}_{11} \underline{Z}_1 + \underline{I}_{33} \underline{Z}_3 = -\underline{E}_3 - \underline{E}_2
\end{cases}$$

Подставляя $\underline{I}_{33} = J_k$:
$$\begin{cases}
\underline{I}_{11}(\underline{Z}_1 + \underline{Z}_4) - \underline{I}_{22} \underline{Z}_1 = \underline{E}_5 - J_k \underline{Z}_4 \\
-\underline{I}_{11} \underline{Z}_1 + \underline{I}_{22}(\underline{Z}_1 + \underline{Z}_2 + \underline{Z}_3) = -\underline{E}_3 - \underline{E}_2 - J_k \underline{Z}_3
\end{cases}$$

#### Реальные токи ветвей:
$$\underline{I}_1 = \underline{I}_{11} - \underline{I}_{22}, \quad \underline{I}_2 = \underline{I}_{22}, \quad \underline{I}_3 = -\underline{I}_{22} - \underline{I}_{33}, \quad \underline{I}_4 = \underline{I}_{11} + \underline{I}_{33}$$

## 4. Расчёт методом узловых потенциалов (МУП)

* Базисный узел: $\varphi_4 = 0$
* Узел с идеальным источником ЭДС $E_5$: $\varphi_1 = \underline{E}_5$

### Уравнения для неизвестных узлов 2 и 3:
$$\begin{cases}
\varphi_2 \left(\dfrac{1}{\underline{Z}_2} + \dfrac{1}{\underline{Z}_3}\right) - \varphi_3 \dfrac{1}{\underline{Z}_3} - \varphi_1 \dfrac{1}{\underline{Z}_2} = \dfrac{\underline{E}_3}{\underline{Z}_3} - \dfrac{\underline{E}_2}{\underline{Z}_2} + J_k \\
-\varphi_2 \dfrac{1}{\underline{Z}_3} + \varphi_3 \left(\dfrac{1}{\underline{Z}_1} + \dfrac{1}{\underline{Z}_3} + \dfrac{1}{\underline{Z}_4}\right) - \varphi_1 \dfrac{1}{\underline{Z}_1} - \varphi_4 \dfrac{1}{\underline{Z}_4} = -\dfrac{\underline{E}_3}{\underline{Z}_3}
\end{cases}$$

### Токи ветвей:
$$\underline{I}_1 = \frac{\varphi_1 - \varphi_3}{\underline{Z}_1}, \quad \underline{I}_2 = \frac{\varphi_1 - \varphi_2 - \underline{E}_2}{\underline{Z}_2}, \quad \underline{I}_3 = \frac{\varphi_3 - \varphi_2 + \underline{E}_3}{\underline{Z}_3}, \quad \underline{I}_4 = \frac{\varphi_3 - \varphi_4}{\underline{Z}_4}$$
$$\underline{I}_5 = -\underline{I}_3 - \underline{I}_1$$

## 5. Метод эквивалентного генератора (МЭГ)

Нахождение тока $\underline{I}_5$ ветви с источником $E_5$:

1. **Напряжение холостого хода $\underline{U}_{xx}$:**
   Разомкнув ветвь 5, определяем напряжение между её зажимами:
   $$\underline{U}_{xx} - \underline{I}_4 \underline{Z}_4 - \underline{I}_1 \underline{Z}_1 = 0 \implies \underline{U}_{xx} = \underline{I}_4 \underline{Z}_4 + \underline{I}_1 \underline{Z}_1$$
   При разомкнутой ветви 5 ток $\underline{I}_4 = J_k$, а ток $\underline{I}_1$ находится из одного уравнения МКТ:
   $$\underline{I}_{11}(\underline{Z}_1 + \underline{Z}_2 + \underline{Z}_3) - J_k \underline{Z}_3 = \underline{E}_3 + \underline{E}_2 \implies \underline{I}_1 = \underline{I}_{11}$$

2. **Входное комплексное сопротивление $\underline{Z}_{вх}$:**
   Пассивируем схему (источники ЭДС закорачиваются, ветвь источника тока размыкается):
   $$\underline{Z}_{вх} = \frac{(\underline{Z}_2 + \underline{Z}_3) \cdot \underline{Z}_1}{(\underline{Z}_2 + \underline{Z}_3) + \underline{Z}_1} + \underline{Z}_4$$

3. **Определение тока ветви:**
   $$\underline{I}_5 = \frac{\underline{E}_г - \underline{E}_5}{\underline{Z}_{вх}} = \frac{\underline{U}_{xx} - \underline{E}_5}{\underline{Z}_{вх}}$$

## 7. Баланс мощностей цепи синусоидального тока

### 7.1. Баланс активной мощности ($\sum P_{ист} = \sum P_{потр}$)

* **Мощность потребителей:**
  $$P_{потр} = I_2^2 R_2 + I_3^2 R_3 + I_4^2 R_4\quad [\mathrm{W}]$$

* **Мощность источников:**
  $$P_{ист} = E_3 I_3 \cos\varphi_3 - E_2 I_2 \cos\varphi_2 - E_5 I_5 \cos\varphi_5 + J_k U_{24} \cos\varphi_J\quad [\mathrm{W}]$$
  где:
  $$\varphi_3 = \psi_{E3} - \psi_{I3}, \quad \varphi_2 = \psi_{E2} - \psi_{I2}, \quad \varphi_5 = \psi_{E5} - \psi_{I5}, \quad \varphi_J = \psi_{U24} - \psi_{Jk}$$

### 7.2. Баланс реактивной мощности ($\sum Q_{ист} = \sum Q_{потр}$)

* **Реактивная мощность потребителей:**
  $$Q_{потр} = I_1^2 X_{L1} + I_2^2 (-X_{C2}) + I_4^2 (X_{L4} - X_{C4})\quad [\mathrm{var}]$$

* **Реактивная мощность источников:**
  $$Q_{ист} = E_3 I_3 \sin\varphi_3 - E_2 I_2 \sin\varphi_2 - E_5 I_5 \sin\varphi_5 + J_k U_{24} \sin\varphi_J\quad [\mathrm{var}]$$

### 7.3. Баланс комплексной мощности

$$\underline{S}_{ист} = \underline{S}_{потр}$$
$$\underline{S}_{ист} = \underline{E}_3 \underline{I}_3^* - \underline{E}_2 \underline{I}_2^* - \underline{E}_5 \underline{I}_5^* + \underline{U}_{24} \underline{J}_k^* = P + j Q$$

Напряжение на источнике тока определяется из контура:
$$\underline{U}_{24} - \underline{I}_4 \underline{Z}_4 + \underline{I}_3 \underline{Z}_3 = \underline{E}_3 \implies \underline{U}_{24} = \underline{E}_3 + \underline{I}_4 \underline{Z}_4 - \underline{I}_3 \underline{Z}_3$$
